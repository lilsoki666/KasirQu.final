# KasirQU 2.0.4 - UI Update

Pembaruan ini menerapkan gaya UI berdasarkan 3 gambar referensi:
- app bar biru dengan nama toko
- judul dan jumlah item/transaksi
- tombol aksi utama `Tambah +` dan `+ Buat Transaksi`
- search + filter
- kategori produk berbentuk chip
- daftar produk dengan foto, harga, stok, Edit, dan Hapus
- daftar transaksi dengan status Dibayar/Dibatalkan dan total di kanan
- checkout memakai judul `Checkout Transaksi` dan tombol `PILIH PEMBAYARAN >`

Sistem lama tetap dipertahankan, termasuk database, 4 kolom produk di menu Kasir, Bluetooth printer tersimpan, cetak otomatis, cetak ulang, backup, laporan, dan picker gambar Android.
