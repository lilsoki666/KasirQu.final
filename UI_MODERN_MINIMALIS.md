# KasirQU 2.0.4 — Modern Minimalis UI

Pembaruan ini fokus pada tampilan dan kenyamanan penggunaan tanpa mengubah alur database, transaksi, pembayaran, printer Bluetooth, cetak struk, foto produk, laporan, backup, atau navigasi.

Perubahan UI:
- Latar belakang dibuat lebih lembut dan bersih.
- App bar biru dibuat konsisten.
- Tombol menggunakan sudut membulat dan hierarki visual yang lebih jelas.
- Field input/search memiliki border halus dan state fokus.
- Card memiliki border tipis untuk pemisahan konten.
- Spacing dan padding diperlonggar agar lebih nyaman disentuh di HP.
- Navigasi bawah dibuat lebih ringkas dengan active state biru yang halus.
- Spinner/pilihan pengaturan dibuat lebih konsisten.
- Grid Kasir tetap 4 kolom sesuai sistem sebelumnya.
