# KasirQU 2.0.4 - UI Navigation Update

Perubahan UI saja, dengan sistem POS yang sudah berjalan tetap dipertahankan.

## Perubahan
- Toolbar bawah disederhanakan menjadi 3 menu utama: Kasir, Produk, Pengaturan.
- Icon toolbar dihilangkan agar tampilan lebih bersih dan ringan.
- Indikator menu aktif menjadi garis biru tipis di bagian atas tombol, bukan kotak/border.
- Riwayat Transaksi dan Laporan dipindahkan aksesnya ke bagian "Menu Lainnya" di Pengaturan.
- Screen Riwayat dan Laporan tetap dipertahankan agar fungsi transaksi/laporan yang sudah ada tidak dihapus.
- Database, checkout, pembayaran, printer Bluetooth, cetak struk/cetak ulang, foto produk, backup, dan sistem lain tidak diubah.
