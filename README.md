# KasirQU v1.5

Android POS / cashier application built with Python + Kivy + Buildozer.

## Included

- main.py
- database.py
- buildozer.spec
- requirements.txt
- GitHub Actions workflow
- KasirQU icon 512x512
- phone-ratio presplash
- image-ready product database support
- Bluetooth/ESC-POS support in the application source

## GitHub build

1. Create a new repository.
2. Upload the complete contents of this folder.
3. Commit to `main`.
4. Open **Actions**.
5. Select **Build KasirQU Android APK**.
6. Click **Run workflow**.
7. Download artifact **KasirQU-debug-apk** after a successful build.

## Do not upload

`.buildozer/`, `bin/`, APK files, or local database files.

## Branding

The app icon is `assets/icon.png`.
The Android presplash is `assets/presplash.png`.
